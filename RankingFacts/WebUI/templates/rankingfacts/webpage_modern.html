Workflow

How it works

Three steps from raw data to fairness insights

1
Upload Your Gene CSV
Provide a CSV where rows are genes in pre-ranked order (rank 1 = first row). Include binary feature columns and a Gene_Name column.
2
Select Gene Features
Choose which binary gene features to analyze for fairness. We pre-load 5 recommended defaults covering variation constraint, localization, essentiality, expression, and RNA stability.
3
Run Fairness Analysis
Three statistical oracles (FA*IR, Pairwise, Proportion z-test) run across all selected features, producing a clear fair/unfair verdict with p-values for each.

Methodology

Three statistical fairness oracles

Each oracle tests a different statistical definition of fairness at significance level α = 0.05

Oracle 1

FA*IR

Tests whether the protected group appears frequently enough at every prefix of the ranking using a binomial CDF with Bonferroni-corrected alpha levels across all ranking positions.

Zehlike et al., 2017 • FA-IR algorithm
Oracle 2

Pairwise

Counts how often a gene in the protected group is ranked above a non-protected gene, compared to a pre-computed simulation distribution of fair rankings.

Returns NA when simulation files are unavailable
Oracle 3

Proportion z-test

Compares the proportion of protected group members in the top-K to their proportion in the full dataset using a two-proportion z-test at the specified significance level.

Based on §4.1.3 of Zliobaite, 2015
