About the fairness oracles

FA*IR
Tests group representation at every ranking prefix using binomial CDF with Bonferroni-corrected alpha.
Pairwise
Compares concordant pair count to a simulation distribution. Returns NA when simulation data is unavailable.
Proportion z-test
Two-proportion z-test comparing top-K group representation to overall dataset proportions.
